# Feature backlog

This backlog tracks product work after Engineering Toolkit closure. Supported
toolkit contracts and explicit deferrals are maintained in
`ENGINEERING_TOOLKIT_CAPABILITY_MATRIX.md`.

## Now

- A-001.1 versioned, allowlisted desktop-to-Python IPC foundation.
- Backend lifecycle and structured failure presentation in the frontend.
- Packaged-development verification for the IPC probe.

## Next

- Prompt and project persistence through existing repository contracts.
- Prompt-library organization, editing, and search.
- Prompt composition with the offline reference provider.
- Workflow authoring and validation UI over the schema-1 Workflow SDK.

## Later

- Controlled provider endpoints and credential storage.
- Managed extension lifecycle UI within established trust boundaries.
- Import/export, backup/recovery, diagnostics, onboarding, accessibility,
  localization, and distribution polish.
- Advanced workflow execution semantics after product requirements are proven.

## Not silently approved

- remote marketplaces or automatic package installation;
- arbitrary plugin/provider/workflow code loading;
- autonomous repository mutation;
- automatic Git, release, signing, or publishing operations; and
- credentials, network access, or telemetry without an explicit reviewed
  product checkpoint.
